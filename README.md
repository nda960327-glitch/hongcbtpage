# 우렁의사 소개 홈페이지

AI 심리상담 앱 **우렁의사**의 공식 소개 페이지입니다.

- **CBT·DBT·MBCT 통합 맞춤 AI 상담** — 로직 챗봇이 아니라 상태(감정 강도·반추·왜곡)를 읽고 치료 접근을 골라 쓰며, 잘 통한 접근을 장기기억에 남겨 다음 대화에 반영
- 성격이 다른 4명의 AI 상담사(우렁의사·햇님·달님·소나무)와 채팅·AI 보이스톡
- 근거기반 셀프케어 도구(사고 기록지 · 인지왜곡 학습 · 마음 대시보드)
- 병원 소속 검증 상담사 매칭·예약, 보이스톡·예약 결제용 우렁 캐시
- 요금: 7일 무료 체험 → 멤버십 월 ₩9,900 / 연 ₩79,000 (33% 할인) · 보이스톡은 멤버십 전용(30초당 150캐시)
- 정산: 상담사 약 80% · 병원 10% · 플랫폼 7% · PG 수수료 3~4% · 인간 상담은 PG 결제, 구독·캐시는 구글 인앱(수수료 15% 순액 기준)
- 병원 파트너 프로그램(상담사 약 80% · 병원 10% · 플랫폼 7% · PG 3~4% 정산)
- 투자자용 시장 기회 섹션(정부 바우처·우울증 진료 100만 명·DTx 허가, TAM/SAM/SOM·성장 플라이휠 다이어그램)과 상담사 모집 섹션(수입 시뮬레이션) 포함

## 구조

`index.html` 단일 파일입니다. 폰트(고운바탕·고운돋움)와 앱 스크린샷이 전부 base64로 내장되어 있어 외부 의존성 없이 어디서나 열립니다. 라이트/다크 테마와 모바일(320px~)부터 데스크톱까지 반응형을 지원합니다.
